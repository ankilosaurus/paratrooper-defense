# Paratrooper Defense

Classic browser game inspired by the 1982 Paratrooper. Protect your cannon from planes and parachuting soldiers.

## Play

Live on Vercel: https://paratrooper-defense-ankilosaurus-projects.vercel.app

## Controls

- **Mouse / touch** — aim the barrel (full 180°)
- **← →** or **A D** — aim
- **Space** or **Click** — shoot

## Rules

- Planes fly across the top and drop soldiers with parachutes
- Shoot planes (100 pts) or falling soldiers (25 pts)
- Landed soldiers walk to the cannon and damage it
- Game ends when cannon HP reaches 0
- High scores saved locally under your name

## Stack

Single-file HTML5 Canvas game. No build step.
